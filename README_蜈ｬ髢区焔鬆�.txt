ブラウザ公開手順（GitHub Pages）

1. https://github.com/chatnoir-4649/- を開きます。
2. Add file → Upload files を選びます。
3. index.html をアップロードして Commit changes します。
4. Settings → Pages を開きます。
5. Build and deployment: Deploy from a branch
6. Branch: main / Folder: /(root) を選んで Save。
7. 数分後、公開URLは通常 https://chatnoir-4649.github.io/-/ になります。

ゲーム本体は index.html 1ファイルで動くようにしてあります。
